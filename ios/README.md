# 九三棋社 · 原生 iOS App

主要产品入口是 `GoKit.xcodeproj`。使用 SwiftUI 编写，面向 iOS / iPadOS 17 及以上；没有 WebView、网页服务器或第三方运行时依赖。

## 功能

- 系统100课基础教学版：90个主题、10次综合复习，450道原创知识判断＋100道抽取复习，每课一项棋盘操作或观察（棋图有复用）。讲解、示范、答题、实战任务和学习记录均可离线使用。
- 新教学棋盘：同机轮流执黑白，支持9/13/19路、放大、悔棋、停手、人工标死子及无贴目面积估算；棋谱逐手回放、从关键手重下、笔记、最多10份手动存档。不是新增的13/19路自动对手。

- 学习入口统一为100课：打开「跟着学」直接查看进度、继续学习和十个单元。复习页同样采用100课，吴清源名局与教练带练归入补充内容。旧48课、百日日程入口下线，历史存档和兼容代码保留。
- 吴清源启蒙课：8 节已核对名局观察课，支持播放 19 路历史棋谱片段；标注书中局号、对手、日期、结果和核对状态，教学解释为九三棋社原创改编。
- 陪练：九路棋盘，先选点再确认落子；查看气、悔最近 30 轮、停一手、恢复练习、盘面估算。
- 对局复盘：记录九路棋局每一步，识别漏吃、未救打吃、自紧气和开局贴一线等关键时刻，标出建议方向并支持从该手之前重新下。
- 复习：错题和依赖提示完成的课进入待巩固列表，重新独立答对后移出。
- 教练带练：三步互动课（数气、提子、救棋），10 道原创配套练习，5 题一轮的针对性练习。
- 五路吃子挑战：先提子获胜，合法落子、白棋自动应手、叫吃标记、撤回一轮与自动存档；双方连续停一手或 80 手上限时和局。
- 自动保存：学习进度、当前棋局、历史盘面及悔棋记录保存在 App 自己的 UserDefaults 中。
- 原生底部导航、动态字体、VoiceOver 棋盘坐标、落子触感、iPhone / iPad 自适应布局。
- 所有课程与陪练离线可用。没有账户、广告、跟踪或远程模型调用。

陪练仍然是入门启发式算法，不是职业围棋 AI。禁自杀、全局同形禁止；白贴 6.5 点仅用于教学估算，不自动判断死活，不宣布正式胜负。用户停一手后陪练也停一手，方便检查棋盘。

上述贴目、地盘估算与停手暂停行为属于九路陪练。五路挑战使用「先提子获胜」的教学规则，不贴目、不数地，黑棋停一手后白棋仍可继续落子。

## 系统100课的使用与验收

入口：**跟着学**。100课全部开放，首页直接展示进度与十个单元。旧48课与百日计划不再作为用户路线展示，其历史记录继续保存，不自动折算成100课成绩。

1. 每课有目标、讲解、例子、棋盘题、知识判断和实战任务。主题课6项，综合复习11项。
2. 逐手观看示范会记录提示；同轮改对不会抹去错误。全部完成记“已学”，本轮独立完成至少80%且最后棋盘题独立完成记“本轮达标”。这不是正式棋力认证。
3. 错题或提示进入「温故知新」。重新独立练一轮保留已学记录，复习债务直到全课独立答对才清除；中途退出保留未完成题的提示/错误。
4. 教学棋盘的双停进入人工终局确认，可标记整块死子、有争议可续下。与「下一盘」九路自动对手及其贴目设置分开。
5. 「保存这盘棋和笔记」保留最多10份记录，满额不会覆盖。逐手回看可从当前位置重下，重下前先保存当前已有着手的教学棋局。新开局替换当前棋盘与未归档笔记，界面会确认。
6. 第26课接不归有两条参考变化，第35课直四接受两处分眼；征子与倒扑需要完成后续，不能只下第一手就过关。示范白棋是预设应手，未穷尽所有合理变化。
7. 原课程方案中的550道独立棋形题尚未完成。当前650项练习包含重复复习与复用棋图；对杀、官子等进阶专题还需补充更丰富的完整棋形证明。题目没有宣称经过职业棋手审定。

内容源：`data/study-course/lessons.txt`；运行 `python3 scripts/build-study-course.py` 生成 `Core/StudyContent.swift`。棋图人工编写在 `Core/StudyDiagrams.swift`。

## 历史百日计划（用户入口已下线）

以下记录保留供兼容维护；当前学习与复习页面均不再进入旧百日日程。

1. 首页显示当前天数、已完成天数、连续闯关天数以及七段路线；计划不按自然日期锁定，从最早未完成的一天继续。
2. 每天包含「今日棋理、专项训练、落盘巩固」三项，分别进入现有课程、带练题、五路挑战、九路对局、复习页或吴清源启蒙课。
3. 完成一项后返回当天页面，点击「练完了，标记完成」；三项全部打勾后自动开放下一天入口。误点可以撤销。
4. 检查第 1–7 天为吃子、第 8–28 天为对杀、第 29–42 天为死活、第 43–49 天为围地数目、第 50–70 天为手筋布局、第 71–90 天为九路实战、第 91–100 天为十九路与名局启蒙。
5. 退出并重新打开 App，任务勾选、当前天数和连续闯关统计应保持。百日计划记录单独保存在 `go-kit.native-hundred-days.v1`，不改变原有课程进度。

## 教练带练的使用与验收

入口：**跟着学 → 专项练习与吴清源名局 → 教练带练**；**下一盘 → 五路吃子挑战**；带练错题同时出现在 **温故知新**。

1. 完成「第一节 · 数气与叫吃」的三个步骤。带练课完成会保存，讲解课本身不计独立掌握。
2. 在救棋步骤故意下在别处：教练应圈出只剩一口气的黑棋，点「演示白棋下一手」查看具体提子，然后「回到题目再试一次」。演示仅针对规则可验证的一手提子，不作无法证明的胜负判断。
3. 进入「完整练一遍」测试 10 道题：数气 3 题、提子 3 题、救棋 2 题、连接 2 题。落子题先选点，再确认；接受所有符合题目目标的合法着法。
4. 答错或使用提示即进入待巩固。本题内重试不会清掉错误记录，下一轮独立答对才移出。离开未完成的题后，下次从题目初始盘面开始；已记录的错误或提示保留。
5. 「练习 5 分钟」每轮从待巩固、未独立答对、已独立答对的顺序选 5 题；这不是按日期锁定的打卡功能。小本领统计表示独立答对题数，不代表正式棋力评级。
6. 五路挑战中先提子者获胜，胜负确定后不能继续落子；撤回一轮可回到黑棋落子之前。检查重启 App 后棋盘、带练进度、错题与撤回记录是否恢复。

## 历史48课、吴清源观察与九路复盘说明

旧48课入口已下线，以下旧课验收记录仅供兼容维护。吴清源名局入口在「跟着学 → 专项练习与吴清源名局」，也可从相应主线课进入。

1. 「跟着学」显示 48 课和七个阶段；原来完成的课程进度应保留，继续学习会从第一节未完成课程开始。
2. 第 9–14 课练强弱、打吃方向、提子救棋、双打和对杀；第 15–20 课练眼形、做活、九路开局、展开与收官。
3. 第 21–28 课练断点、虎口、竹节、征子、引征、枷、倒扑和接不归；第 29–36 课练直三、曲三、方四、扩大和缩小眼位、假眼、双活与劫活。
4. 第 37–44 课练九路方向、急场、弱棋、攻击、打入和浅消、厚势、先手与官子；第 45–48 课建立候选点、读三步、落子检查和自主复盘流程。
5. 进入「吴清源启蒙课」，8 课均可从初始局面播放历史棋谱片段。完成问题后单独保存进度；页面应明确说明讲解不是原书评注。
6. 在「下一盘」至少下一轮，点击「暂停并复盘」。复盘页最多给出 5 个关键时刻，半透明黑子表示本局落点，绿色虚线圈表示建议方向。
7. 故意漏掉一块只剩一口气的白棋，复盘应提示「别错过提子」；故意让新棋块只剩一口气，应提示「给自己多留气」。
8. 点击「从这里重新下」，九路棋盘应恢复到该手之前；课程、带练与错题记录不受影响。旧版本保存的棋局可以继续读取，只是升级前的棋步没有逐手复盘记录。

新增记录使用 `go-kit.native-coach.v1`、`go-kit.native-hundred-days.v1`，原有 `go-kit.native-learning.v1` 课程与九路棋局记录保留。带练入口、习题和挑战使用 SwiftUI，不依赖预览页面或局域网服务器。

## 用 Xcode 打开

1. 安装完整 Xcode（建议 16 或以上）以及其中的 iOS Simulator runtime。
2. 打开本目录的 `GoKit.xcodeproj`，选择共享 Scheme `GoKit`。
3. 选择一个 iPhone 模拟器，点击 Run。模拟器运行不需要选择开发团队。
4. 要在自己的 iPhone 上运行：在 Xcode 登录 Apple 账号，在 GoKit target 的 Signing & Capabilities 中选择自己的 Team，连接并信任设备，按系统提示开启 Developer Mode，然后选择该设备运行。

默认 Bundle ID 是 `com.percival.gokit`；如果你的签名账号提示该标识不可用，改成自己唯一的 Bundle ID。

## 在自己的 iPhone 上试用

当前建议先用 Xcode 直接安装，完成首轮真机检查后再分发 TestFlight。

### 免费个人测试

1. 安装与这台 Mac、手机系统版本兼容的完整 Xcode，并安装 iOS 平台支持。
2. 打开 `GoKit.xcodeproj`，在 Xcode Settings → Accounts 登录自己的 Apple Account。
3. 选择 GoKit target → Signing & Capabilities，勾选 Automatically manage signing，Team 选择自己的 Personal Team。
4. 用数据线连接 iPhone，按提示信任电脑、开启手机的 Developer Mode。
5. 在 Xcode 顶部选择自己的 iPhone 和 GoKit Scheme，点击 Run；编译和签名成功后，App 会安装到手机。

免费 Personal Team 的 provisioning profile 有效期为 7 天，过期后可能需要重新构建、安装。无需先开通付费会员。

### TestFlight 持续测试

分发者需要 Apple Developer Program 会员（标准价每年 99 美元，或当地货币价格）和 App Store Connect；手机上的 TestFlight 免费。

1. 先完成 iOS 构建及真机检查，配置付费开发团队签名、唯一 Bundle ID，并在 App Store Connect 创建 App 记录。
2. Xcode 中选择通用 iOS 真机目标，通过 Product → Archive 构建归档，再通过 Distribute App 上传至 App Store Connect。
3. 等待构建处理完成，补全 TestFlight 测试信息及所需合规信息，添加测试人员。外部测试的首个构建需要 Beta App Review；后续构建可能仍需审核。
4. iPhone 安装 Apple 的 TestFlight，通过邮件邀请或公开邀请链接接受测试并安装。

TestFlight 每个构建最多可测试 90 天，后续可上传新构建更新；不需要先公开上架 App Store。当前项目尚未签名或上传，没有可用的 TestFlight 邀请链接。

官方说明：[会员与免费测试限制](https://developer.apple.com/support/compare-memberships/)、[TestFlight 流程](https://developer.apple.com/help/app-store-connect/test-a-beta-version/testflight-overview/)。

`output/playwright/go-kit-ios-preview.html` 是根据 SwiftUI 页面制作的可交互设计预览，PNG 预览同样不是模拟器或真机截图；其中的进度与棋局是演示数据。

[Apple 的设备运行说明](https://developer.apple.com/documentation/xcode/running-your-app-on-simulated-or-physical-devices)

命令行构建（仅在安装完整 Xcode 和对应 SDK 后可用）：

```sh
xcodebuild -project ios/GoKit.xcodeproj -scheme GoKit \
  -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath .build/ios CODE_SIGNING_ALLOWED=NO build
```

```text
ios/
  GoKit.xcodeproj/        Xcode 工程与共享运行 Scheme
  GoKit/
    GoKitApp.swift        App 生命周期及底部导航
    AppStore.swift        学习进度、棋局、本机存档

```
