## 本轮实际内容

- 90节主题课：目标、原创讲解、例子、5道知识判断、1项棋盘操作或观察、实战任务。
- 10节综合复习：每次从本单元主题抽取10题，加1项棋盘任务。
- 650个练习记录ID = 450道编写的知识判断 + 100道抽取复习 + 100项棋盘任务。棋图有复用，**不是650道独立棋图，也未完成原设计550道独立棋形题**。
- 逐手演示；第26课接不归展示连接/不连接两条线，第35课接受两处分眼。征子需走到实际提取，倒扑需完成反提。其余自动白棋多为单条预设应手，不宣称穷尽最强抵抗。
- 已学、本轮独立达标、待巩固分别记录。独立达标阈值为至少80%且最后棋盘题独立完成；全课重新独立完成才清除复习记录。看提示、中断、再进课均保留相关证据；完成后单纯回看示范不倒扣已得成绩。
- 9/13/19路同机教学棋盘，先选点确认，白子预览用白色，13/19路可放大；双方停手后人工标死子、确认边界，面积估算不贴目，有争议可续下。
- 逐手回看、复盘笔记、从某手之后重下、最多10份完整教学棋谱。满额不覆盖；主动删除有确认。新开局会替换未归档当前棋局并先确认。教学棋盘没有新增自动AI对手，原九路陪练仍可使用。
- 系统课相关位置链接已有吴清源观察课；没有冒充吴清源原书评注或职业棋手审定。

## 来源与生成

课程次序和目标来自 `docs/curriculum-v2.csv`，资料依据见 `docs/curriculum-v2.md`。公开资料用于教学范围、规则和顺序参考；本目录讲解和选择题为项目编写，没有复制书内原题。

`lessons.txt` 为90节主题内容源，每行：编号、讲解、例子、五组“问题~正确理解~干扰理解”。综合题由脚本组合复用。

```sh
python3 scripts/build-study-course.py
sh scripts/test-ios-core.sh
```

生成 `ios/GoKit/Core/StudyContent.swift`，无需联网下载内容。棋图与应手在 `ios/GoKit/Core/StudyDiagrams.swift` 人工维护，全部变化通过 GoEngine 合法性回放。测试检查提取结果及存档逻辑，**不能代替全面的棋理与教学质量审校**。
