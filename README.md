# 九三棋社（iOS）

面向零基础的原生 iOS 围棋学习工具。主要实现已转向 **SwiftUI iPhone / iPad App**，工程入口为 [`ios/GoKit.xcodeproj`](ios/GoKit.xcodeproj)，完整运行说明见 [`ios/README.md`](ios/README.md)。

App 以系统100课基础教学版为唯一课程主线，学习页直接显示进度与十个单元，复习页使用同一套课程。另有9/13/19路同机教学棋盘与棋谱笔记、吴清源名局观察、教练带练、五路吃子挑战、九路离线陪练及本机存档。旧48课与百日日程已撤下用户入口，历史存档保留。最低系统版本为 iOS 17。真机安装需要完整 Xcode 和 Apple 账号签名。

课程方案见 [课程设计 v2](docs/curriculum-v2.md) 与 [100单元课程清单](docs/curriculum-v2.csv)：含专业资料依据、每课目标与练习、验收标准、吴清源支线和旧课迁移。目前已实现100课讲解与650项练习入口，其中450道原创知识判断、100道抽取复习、100项棋盘操作或观察（棋图有复用）。设计中的550道独立棋形题及完整应手树尚未完成，不能用入口数量代替独立题库数量。当前实现与验收说明见 [课程制作记录](data/study-course/README.md)。

## 启动

使用 Node.js 20 或更新版本：

```sh
npm start
```

打开 http://127.0.0.1:5173 。可通过 `PORT` 更改端口。

固定局域网入口：**http://go-kit.local/**。登录后自动启动，具体服务及域名路由配置见 [局域网访问说明](docs/lan-access.md)。该地址与原开发地址的学习进度分别保存。

## 功能

- 8 节互动课程：落子、气、提子、逃子、连接、两眼、劫、数子。
- 落子练习、找气、选择题、分步提示及错题复习。
- 学习进度保存在当前浏览器 localStorage；清除浏览器数据会清除进度。
- 九路本地规则陪练、提子统计、悔棋一轮、停一手和盘面估算。
- 自适应桌面 / 手机布局，棋盘交叉点支持键盘聚焦及回车落子。

## 教学与规则边界

不是柯洁本人、官方课程或职业级围棋引擎。陪练使用本地启发式算法，没有调用大模型或 KataGo。默认你执黑、陪练执白。基础规则参考 [英国围棋协会入门说明](https://britgo.org/intro/intro2.html)。

落子禁止自杀，提取对方无气棋块后再检查自身的气；禁止落子后重复任何历史盘面（positional superko），停一手不受限制。白贴 6.5 点仅用于教学盘面估算。估算使用盘上子数加单方围住的空点，不自动判断死活，未移除死子，不能用来宣布正式胜负。用户停一手后陪练也停一手，方便暂停检查棋盘，可以继续下棋。

课程完成与错题状态会保存；当前练习棋局刷新后重置。使用提示完成的错题会保留在复习列表，需要重新独立完成才能移出。字体使用可选 Google Fonts，加载失败时回退到系统中文字体。
