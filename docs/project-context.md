# 九三棋社：项目上下文

这份文档记录已经确定的产品方向和当前实现，供后续开发接续。课程细节以[课程设计](curriculum-v2.md)、[内容制作记录](../data/study-course/README.md)和实际代码为准；变更功能后同步更新这里。

## 产品方向

- 九三棋社是一款面向围棋初学者的**原生 iOS App**，界面和教学语言为中文。SwiftUI 工程在 [`ios/GoKit.xcodeproj`](../ios/GoKit.xcodeproj)，最低系统版本为 iOS 17。
- **系统100课是唯一课程主线**。打开「跟着学」直接看到继续学习和十个单元；「温故知新」使用同一套课的错题记录。旧48课和旧百日计划已撤下用户入口，其代码及本机历史存档保留，不自动换算为100课成绩。
- 吴清源名局观察和教练带练是补充内容。用户对吴清源及《勇气与真意》有兴趣，但该书尚未逐章用作课程依据；不要把项目的讲解写成吴清源或其他职业棋手的原话。
- 用户选择的是 iOS App，不再以早期网页原型为产品主线。`go-kit.local` 是旧网页原型的局域网地址，iOS App 本身不依赖它。

## 当前已有的能力

- 100课分为90节主题课、10节综合复习。每节主题课有讲解、例子、5道知识判断和1项棋盘操作或观察；综合课复用本单元题目。目前共650个**练习记录 ID**：450道编写的知识判断、100道抽取复习、100项棋盘任务。棋图存在复用，不能称为650道独立棋形题。
- 课程支持逐手示范、错误与提示记录、重新独立练习。完成全部题记为「已学」；本轮至少80%独立完成且最后的棋盘任务独立完成，记为「本轮达标」。用过提示或答错的课进入复习页。实战任务由学习者自记，不计入答题正确率。
- 教学棋盘支持9、13、19路同机轮流执黑白、棋谱逐手回看、从关键手重下、复盘笔记和最多10份手动归档。双方停手后可人工标记死子并做无贴目面积估算；这不是13/19路自动对手。另有原九路规则陪练与五路吃子挑战。
- 吴清源启蒙观察课有8节，使用核对过的历史棋谱片段，教学解释为本项目编写。相关主线课可跳转到观察课。
- 学习进度、棋局和笔记保存在本机。课程与棋盘离线可用；外部资料链接需要网络。

## 内容依据与诚实边界

用户提供过其他围棋课程目录图片，作为知识范围参考。课程顺序综合参考日本棋院的入门教学、英国围棋协会的初学者教学建议等公开资料；来源、具体核验范围和规则差异见[课程设计](curriculum-v2.md)。课文和知识判断题由本项目编写，没有照搬书内习题，也**未经职业棋手逐题审定**。

《吴清源自选百局》的[数据目录](../data/go-seigen-selected-100/README.md)含100个书目条目，当前可靠关联32份完整主线 SGF，余下68局尚未可靠对应。另一个[93局公开选集](../data/go-seigen-public-93/README.md)不是该书的完整百局，不能混用。历史棋谱主线与书中评注也不能混为一谈。

## 下一步重点

1. 按[内容制作记录](../data/study-course/README.md)逐题补充独立棋形、反例和真实应手分支。原设计目标是550道**独立棋形根题**；目前的知识判断、抽取复习和复用棋图尚未达到这个目标。先补引征、枷的多出口、接不归、复杂眼形、对杀、短定式反击和官子变化。
2. 对进阶题做棋理与教学难度审校。现有自动检查能验证落子合法、提子结果和存档行为，不能证明每道题的战略评价或最强应手。
3. 补足实战错题谱的局面编辑与变式、不同学习日的复习机制，并完成真机触控、动态字体及无障碍验收。当前也没有 TestFlight 发布版本。

## 开发入口与验证

- 课程大纲：[`docs/curriculum-v2.csv`](curriculum-v2.csv)。90节讲解与判断题内容源：[`data/study-course/lessons.txt`](../data/study-course/lessons.txt)。运行 `python3 scripts/build-study-course.py` 生成 `ios/GoKit/Core/StudyContent.swift`；棋图与预设应手在 `ios/GoKit/Core/StudyDiagrams.swift`。
- 主界面：`ios/GoKit/Views/StudyCourseView.swift`；进度与棋盘存档：`ios/GoKit/AppStore.swift`。棋盘规则：`ios/GoKit/Core/GoEngine.swift`。
- 在仓库根目录运行 `sh scripts/test-ios-core.sh`。此前通过7478项核心检查，并完成 iOS 模拟器构建及首页/课程页面检查。文档修改后不必用这个旧数字代替后续验证。
- 真机调试参见 [`ios/README.md`](../ios/README.md)：用 Xcode 打开工程，选择自己的 Apple 开发团队与已连接的 iPhone，再运行 App。签名、开发者模式与连接信任由 Xcode/设备状态决定；目前没有确认用户真机上的最终运行结果。
- 公共 GitHub 仓库是 [`curme/go-kit`](https://github.com/curme/go-kit)，主分支为 `main`。提交前检查 `.gitignore`，不要加入 `.lody/` 附件、`.build/` 产物或凭据与签名文件。
